# WeKnora P5 故障处置与恢复清单

状态：演练模板；截至 2026-09-27 尚未在真实 WeKnora、PostgreSQL、索引与模型供应商环境执行。生产 RPO/RTO、告警阈值、值守人、备份路径及保留期均待业务和运维确认。

| 现象 | 先看证据 | 处置与恢复核对 |
| --- | --- | --- |
| OCR/Embedding/重排/生成出现 429 | 供应商状态、阶段错误率、队列积压、费用、trace ID | 按供应商限制退避；保护在线问答额度；不要把任务标记成功；恢复后按幂等键重投，检查重复计费。 |
| 5xx 或超时 | 供应商状态、请求耗时、租约代次和外部任务 ID | 有界重试；超时但供应商已接收时先查外部状态；旧代次结果不得覆盖新构建。 |
| 401/403/配置错误 | 身份映射、凭据引用、权限审计和最近配置变更 | 停止自动快速重试，转人工处置；恢复凭据/权限后重验一条允许和一条拒绝路径。不得在日志打印密钥。 |
| Worker 中断或 Outbox 重投 | 待投递量、租约到期、尝试次数、下游幂等记录 | 等旧租约过期再领；处理器按事件 ID 幂等；只在副作用确认后 ACK，检查重复处理与遗漏。 |
| 索引失效/旧块残留 | 构建清单、活动发布快照、检索 `degraded`、来源版本 | 暂停受影响索引路径并明确降级；从固定产物重建，验证数量和可读性；旧块即使残留也不得通过发布与 ACL 闸门。 |
| 缓存展示旧制度或越权 | 发布 epoch、ACL 修订、业务有效时刻、逐来源读取判定 | 停止对应缓存层，复验当前权限和来源；重建键/配置后再开启；不得仅靠 TTL 等待失效。 |
| 评测退化或冲突上升 | 当前数据集版本、提案清单、配置/代码指纹、逐类失败样本 | 发布保持阻断；业务审核人复核制度、合同和例外；修复后新运行并独立批准。 |

## 备份恢复演练记录模板

1. 冻结演练范围、目标 RPO/RTO、授权负责人和隔离环境；记录数据库迁移版本、应用镜像、索引配置、模型配置与对象存储清单。
2. 备份原件、文档/版本/ACL/发布/反馈/评测/审计元数据和配置。记录校验和、创建时间、保留位置及访问控制；凭据只保存引用。
3. 在隔离环境恢复 PostgreSQL 与原件，检查记录数、外键、活动发布指针、ACL 修订和 Outbox；从原件与固定处理产物重建索引，不把旧索引文件视为唯一备份。
4. 以授权、无权、过期、撤销、历史和冲突样本核对原件定位、检索、引用与答案状态；重放一次可幂等事件，并检查派生内容隔离。
5. 记录真实恢复耗时、数据差距、费用、失败原因和回退办法，由业务和技术负责人签字后才可作为 P5/P6 验收证据。
