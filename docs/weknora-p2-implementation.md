# WeKnora P2 解析、清洗、切分与索引实施记录

记录日期：2026-09-27  
阶段状态：**可测试的处理内核已实现；P2 尚未通过真实文档与服务集成验收**。P0、P1 的正式集成闸门仍未关闭，不能因本次合成测试通过而启用员工查询。

## 1. 本次阶段目标

依据[开发文档 P2](weknora-development-plan.md#p2解析清洗切分与索引)与[技术文档第 5～8 节](weknora-technical-design.md#5-解析与标准化产物)，先形成可重复调用的入库路径：按来源段选择原生或 OCR 解析器、保存结构和原文位置、检查质量、记录保守清洗、按语义边界切分、批量调用 Embedding、以预切分模式暂存关键词与向量索引，并由 P1 发布闸门再次核对。失败材料进入待复核记录；流水线不自动发布。

## 2. 已实现的源码

| 目标 | 实施内容 | 位置 |
| --- | --- | --- |
| 标准解析产物 | `SourceLocation` 支持 PDF 页/Word 段落/表格单元格；按段路由原生与 OCR 解析接口，检查解析器回传的来源引用和位置 | [processing.ts](../src/knowledge/processing.ts) |
| 质量闸门 | 检查漏页/缺段、解析失败、空页、乱码、原文范围、阅读顺序、表头/列数、跨页表格延续关系 | [processing.ts](../src/knowledge/processing.ts) |
| 保守清洗 | 原始块保持不变，清洗副本只规范空白或去除跨页重复的非关键页眉页脚；每次变更保留原文哈希、规则版本和原因；正文重复只列候选，不自动合并 | [processing.ts](../src/knowledge/processing.ts) |
| 语义切分 | 模型只能返回已有块 ID 作为边界；非法结果回退到结构切分；按真实注入的 tokenizer 计数并限制父子片段长度，核验全部块只覆盖一次 | [chunking.ts](../src/knowledge/chunking.ts) |
| Embedding | 按条数与 token 上限批量，检查模型名、ID、维度与有限数值；仅临时错误有限重试，按租户/模型/文本哈希使用注入缓存 | [embedding.ts](../src/knowledge/embedding.ts) |
| 暂存索引 | 插件自有 P2 迁移记录清单、片段来源和预览引用；索引接口必须确认 `presplit`、双路索引、模型/维度及精确片段 ID，旧代次和同代次不同清单被拒 | [staged-index.ts](../src/knowledge/staged-index.ts)、[迁移](../plugins/knowledge/migrations/0002_p2_staged_index.up.sql) |
| 入库编排 | 从登记的不可变版本读取原件并核对 SHA-256，串联上述步骤；可信外发策略明确允许原文时不擅自脱敏，要求脱敏但无适配器时拒绝调用；质量异常留待复核记录并保持构建不可发布；正常构建就绪但不自动发布 | [pipeline.ts](../src/knowledge/pipeline.ts) |

解析器、原件读取、语义边界模型、Embedding API、缓存、索引服务、外发策略和预览产物存储均由明确接口注入。用户已决定 OCR/Embedding 供应商以后选择；用户明确指定无需脱敏的资料应保持原文，外发授权仍由可信策略判断。当前没有把任何供应商的模型响应或测试替身称为正式 OCR、Word/PDF 解析能力。预切分回执适配器尚未接入 WeKnora，数据库暂存清单本身不是可搜索索引。
